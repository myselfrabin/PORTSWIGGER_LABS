End Goal: Determine the number of column return by the query

Let's first have some UNION background.

table1                    table2
a | b(column)             c | d(column)
--------------            --------------
1, 2                      2, 3
3, 4                      4, 5

Query#1: SELECT a,b from table1
  ==> 1,2
      3,4

Query#2: SELECT a,b FROM table1 UNION SELECT c,d FROM table2
==>      1,2
         3,4
         2,3
         4,5

Rule while using the UNION operator in SQL:
1. The number and the order of the column must be same in the all queries
2. The datatype must be compataible
