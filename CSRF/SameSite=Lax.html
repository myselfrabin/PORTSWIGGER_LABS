🛡️ CSRF Attack Example & Strong Cookie Guide

🎯 Goal:

  • Show how CSRF attack works
  • Show how to prevent it with SameSite and secure cookies

🧑 Victim's Side: vulnerable-site.com

Victim is logged in, and cookie is set like this:

Set-Cookie: sessionid=abc123; Path=/; HttpOnly;

But it has no SameSite, so it's sent with all requests.

💣 Attacker's Site (attacker-site.com)

The attacker makes this auto-submitting form:

<html>
  <body>
    <form action="https://vulnerable-site.com/change-email" method="POST" id="csrfForm">
      <input type="hidden" name="email" value="hacker@evil.com">
    </form>
    <script>document.getElementById("csrfForm").submit();</script>
  </body>
</html>

Result: Email gets changed to hacker's without user's knowledge!

🔒 How to Make Cookie Strong

✅ Fix #1: SameSite=Lax

Set-Cookie: sessionid=abc123; Path=/; HttpOnly; SameSite=Lax

Blocks cross-site POST requests — CSRF fails!

✅ Fix #2: SameSite=Strict

Set-Cookie: sessionid=abc123; Path=/; HttpOnly; SameSite=Strict

Only allows cookie in same-site context. Safer but may affect usability.

✅ Fix #3: Use CSRF Token

Example:

<form action="/change-email" method="POST">
  <input type="hidden" name="csrf_token" value="abcde12345">
  <input type="email" name="email">
</form>

🔐 Final Strong Cookie Recommendation

Set-Cookie: sessionid=abc123; Path=/; HttpOnly; Secure; SameSite=Lax
  • HttpOnly: Protects from JavaScript (XSS defense)
  • Secure: Only sent over HTTPS
  • SameSite: Defends against CSRF
  • CSRF Token: Adds extra security

📘 Nepali Summary (नेपालीमा सजिलोमा बुझौं)

SameSite=Lax ले cross-site बाट आएको POST request मा cookie पठाउन दिँदैन। यसले CSRF रोक्न सहयोग गर्छ।

SameSite=Strict ले बाहिरी site बाट आएको कुनै पनि request मा cookie पठाउँदैन। यो अझ कडा सुरक्षा हो।

HttpOnly ले JavaScript बाट cookie चोर्ने XSS हमला रोक्छ।

Secure ले cookie केवल HTTPS मा मात्र पठाउन दिन्छ।

CSRF token ले वास्तविक user बाट आएको request हो कि होइन भनेर confirm गर्छ।

📊 सारांश तालिका

SameSite सेटिङ GET मा cookie? POST मा cookie? उपयुक्त प्रयोग
Strict ❌ ❌ अत्यधिक सुरक्षा
Lax ✅ ❌ सामान्य login/session
None ✅ ✅ 3rd-party tools, but Secure=true अनिवार्य

अब तिमीले CSRF कसरी काम गर्छ र यसलाई रोक्न के गर्ने भन्ने गहिरो बुझाइ पायौ। 💡
